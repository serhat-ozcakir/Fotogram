## 📖 Overview

Fotogram is a modern and responsive image gallery inspired by Instagram. Users can browse image thumbnails, open photos in a fullscreen lightbox and navigate through the gallery using intuitive controls.

The project focuses on dynamic rendering, responsive layouts and an enjoyable user experience using vanilla JavaScript.

---

## ✨ Features

- 🖼️ Dynamic image gallery
- 🔍 Fullscreen image preview
- ⬅️ Previous & Next navigation
- 🖱️ Thumbnail hover effects
- ❌ Close image dialog
- ⌨️ ESC key support
- 📱 Fully responsive design
- ⚡ Optimized image loading

---

## 🛠 Tech Stack

- JavaScript (ES6)

- Responsive Design

## 🚀 Main Functionality

- Display image thumbnails
- Open images in fullscreen view
